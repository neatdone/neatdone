# NeatDone — Your mess, neatly done.

NeatDone is a to-do list and daily planner for capturing tasks, breaking projects into steps, and planning a realistic day. Use it without an account; sign in with Google only to sync tasks across the Web and Android app.

Website: https://neatdone.com

## How it works

1. Dump it — A paragraph, three abbreviations, a scribbled list. Any shape works.
2. We sort it — Split into the few real tasks and their steps, with times and deadlines picked out.
3. Time-blocked — Placed into real hours, with lunch and slack left alone.
4. Review, then stop — Tick off what happened, write three lines, and tomorrow already has a first step.

## Features

- One page for today: Scheduled, doing, done — all in one place.
- Steps, not piles: A big thing becomes moves you can start in the next five minutes.
- A week and a month, at a glance.
- Works offline: Keep writing on a plane. It syncs when you land.
- Phone + web: One account, the same tasks on both.
